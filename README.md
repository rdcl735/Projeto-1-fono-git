# Projeto 1 - Landing Page Fonoaudiologia 🗣️

Este projeto é uma landing page profissional e moderna desenvolvida para a **Dra. Carolina Mendes**, fonoaudióloga. O site foi projetado para transmitir confiança, profissionalismo e acessibilidade, facilitando o agendamento de consultas e a apresentação de tratamentos especializados.

## 🚀 Sobre a Aplicação

A aplicação é um site de página única (Single Page Application) responsivo, focado em conversão e experiência do usuário (UX). Ela apresenta as especialidades da profissional, sua trajetória acadêmica e diversos canais de contato direto.

### ✨ Funcionalidades Principais
- **Design Responsivo:** Adaptado para dispositivos móveis, tablets e desktops.
- **Seção Hero:** Chamada visual impactante com badges de especialização e estatísticas de atendimento.
- **Sobre Mim:** Detalhes sobre a formação acadêmica e missão da profissional.
- **Áreas de Atuação:** Grade de tratamentos especializados (Linguagem, Motricidade, Voz, etc.) com ícones e descrições claras.
- **Canais de Contato:** Integração direta com WhatsApp, Telefone e E-mail, além de visualização de endereço e horários.
- **Navegação Inteligente:** Menu mobile interativo e cabeçalho dinâmico que reage ao scroll.

## 🛠️ Tecnologias Utilizadas

O projeto foi construído seguindo as melhores práticas de desenvolvimento web moderno, utilizando apenas tecnologias nativas:

- **HTML5:** Estrutura semântica e SEO-friendly.
- **CSS3 (Vanilla):** Estilização personalizada, utilização de variáveis CSS, Grid Layout, Flexbox e animações suaves.
- **JavaScript (Vanilla):** Lógica simples para interatividade do menu mobile e efeitos de interface.
- **Google Fonts:** Tipografia premium utilizando as fontes *Outfit* e *Inter*.

## 📂 Como Visualizar o Projeto

Para visualizar a landing page localmente, basta seguir estes passos:

1. Clone ou baixe este repositório.
2. Navegue até a pasta raiz do projeto.
3. Abra o arquivo `index.html` em qualquer navegador web moderno.
